# 規格與驗收

- F1：HTTP(S) 網址輸入產生 PNG，顯示版本、模組、容錯、像素和位元組大小。
- F2：手機掃描公開網址後確實開啟；須裝置證據。
- F3：獨立解碼器解碼圖片並與輸入精確比較，無法解碼或不符即失敗。
- F4：本機服務顯示實際可達位址並產生 QR；兩台裝置掃描，不能以本機請求冒充。
- F5：網頁顯示提供的真實學號姓名；每個 HTTP 請求保存時間、來源 IP、User-Agent；IP 不等同裝置數。未提供身分則明示待填。
- F6：同網址 L/M/Q/H 圖片，列出版本、模組、像素、檔案大小及實際解碼結果；實體掃描可讀性另驗。
- F7：QR 下方文字標籤，保留靜區並解碼比對；手機掃描另驗。
- F8：頁面具本機互動，不需蒐集訪客個資。
- 報告：自訂題目及目的、3.1–3.9，以真實結果及證據填寫；故障未發生時實測大 Logo 造成無法掃描。make、serve 執行結果保存在 results；測試資料和 IP 要檢視後再交付。

## 本機紀錄後台擴充（2026-11-12）

- 後台使用電腦本機 `http://127.0.0.1:<埠>/admin`，只允許來自 loopback 且 Host 為本機地址的請求；不能由區域網路其他裝置存取紀錄。繼續提供手機可連線的公開導引頁。
- 讀取 `results/connections_*.jsonl`（含過往各次），顯示時間、IP、User-Agent、路徑、狀態、紀錄來源，最新優先；顯示全部網站請求數與首頁 GET 數，明說兩者均非掃描次數或裝置數。可手動重新整理並提供空狀態；保留紀錄，不提供刪除功能。
- 僅載入最新 1000 筆供畫面顯示並標示截斷；格式錯誤列跳過並提示數量。顯示資料應以文字寫入避免日誌內容執行腳本；不得允許一般訪客直接取得後台或 API。
- 原有 QR、手機頁、請求紀錄及所有既有證據保留；先測試再實作，後台由瀏覽器實際操作驗證。新增版本需與先前兩台裝置測試版本分開，舊 ZIP 不得冒稱包含後台。

## 中央 Logo 擴充（2026-11-12）

- `make --logo` 可使用程式內建的簡潔標記，`--logo 圖檔` 可使用自行提供的圖；可與外部文字標籤同用。未指定容錯等級時自動使用 H；若明確指定其他等級應明確拒絕，避免誤認為已使用 H。
- Logo 限制在 QR 中央的小範圍，保留周圍靜區，輸出 PNG 後由 OpenCV 解碼、與網址精確比對；失敗不可聲稱可掃描且應回傳非零。真實手機掃描仍須另外驗證。
- 缺少或無法讀取的 Logo 圖檔應清楚回報，不產生成功紀錄；不覆寫原始 Logo，既有不帶 Logo 的命令相容。

2026-11-12 使用者指定 F6 比較對象改為本機網站 8000 埠；L/M/Q/H 同一 LAN 網址、相同模組像素尺寸且不加 Logo，以單純比較等級；各圖均由程式解碼比對，手機可讀性依使用者實測回報。

## 後台時段篩選（2026-11-12）

- 管理頁提供開始與結束的本機日期時間欄位，可單獨使用、一起使用、套用及清除；結束時間包含所選的整分鐘。顯示目前套用範圍，重新整理沿用範圍，空結果清楚提示。
- 以瀏覽器本機時區解析欄位並轉換為含時區的時間傳給本機 API，後端以絕對時間篩選所有歷史檔後再限最新 1,000 筆，統計同步反映指定時段。開始含該時間、結束為所選分鐘之後的排他邊界。
- 無效時間或結束早於開始不得誤顯示成功；API 驗證無效、未附時區與顛倒時間。仍保留本機存取限制、原始紀錄與網站請求不等於掃描次數的說明。

## 設備點名（2026-11-13）

- 公開頁提供可自行修改的設備型號文字欄位及送出按鈕，送出前說明會記錄型號與來源 IP；保留原按鈕及學號姓名。
- 伺服器驗證型號不得空白、最長 80 字元，限制請求大小，以實際連線來源記錄 IP 和時間，寫入獨立 JSONL；不可接受用戶假冒 IP。
- 僅本機後台/API 查看點名紀錄，套用相同時段範圍，顯示最新紀錄、空結果與錯誤；輸入文字不可當成 HTML 執行。IP 或型號不保證裝置身分。

## 問卷表單（2026-11-13）

- 公開頁提供必選滿意度及可自行填寫的選填建議（最多 500 字），清楚顯示送出結果。
- 問卷與點名獨立記錄時間、滿意度與建議；僅本機後台可查看及依既有時段篩選；清楚標示筆數非裝置數，避免將填答當成掃描數。
- 伺服器限制輸入大小及選項，安全顯示文字，無效與儲存失敗不可宣稱送出成功。保留舊紀錄及舊版交付檔。
