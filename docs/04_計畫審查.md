## 後台擴充實作前審查（2026-11-12）

- 要讀取既有每輪 JSONL，不可把前後台存取或 favicon 數量稱為掃描數；首頁也可由直接輸入、重整、預覽產生。
- 既有站台綁定所有介面，若直接把紀錄檔置於 site 會洩露訪客資訊；後台與 API 僅在 loopback、可信 Host 下提供，網路訪客不得存取；輸出採 DOM textContent 防止 User-Agent 注入。這不是強化身分驗證的正式網路服務。
- 需處理空資料、受損記錄、紀錄筆數上限、檔案失敗、來源排序與多執行緒寫入；手動重整時不得清除或變更日誌。保留先前手機實測，區分新程式碼雜湊後尚未重新以手機驗證。
- 本機 UI 測試會產生新的 HTTP 請求，要記錄為電腦自測，不得冒充手機掃描；ZIP 若更新必須保留原繳交版與證據。
